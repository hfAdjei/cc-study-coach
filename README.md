# CC Study Coach

A small, browser-based study companion for the ISC2 Certified in Cybersecurity (CC) exam.

## What it includes

- Five CC study domains with concise notes
- Foundation, Exam-ready, and Challenge practice questions
- Notes and progress saved in the browser
- A curated YouTube study path for each domain

## Use it

Open `index.html` in a browser, or visit the GitHub Pages site after publishing.

Progress and notes stay on the device you use to study.
